📖 Guía Rápida

1. Iniciar los 3 servicios del lote:

.\start_batch_all.ps1 -Batch 1

2. O iniciar individualmente:

.\start_prodigy_batch.ps1 -Type pos -Batch 1 -Port 8080
.\start_prodigy_batch.ps1 -Type features -Batch 1 -Port 8081
.\start_prodigy_batch.ps1 -Type relations -Batch 1 -Port 8082

2b. O directamente con python:

$env:PRODIGY_PORT=8080; python -m prodigy guarani-batch guarani_pos_batch_01 --type pos --batch 1 -F recipes\guarani_batch.py

3. Flujo de anotación:

Cada lote tiene 50 oraciones. Anota las mismas oraciones en los 3 tipos para que luego se puedan combinar (matching).

4. Combinar anotaciones:

python scripts\match_annotations.py --batch 1 --output data\export

5. Atajos de teclado en Prodigy:

Ctrl+Shift+C = Ver contexto completo
A = Aceptar | X = Rechazar | Space = Ignorar
